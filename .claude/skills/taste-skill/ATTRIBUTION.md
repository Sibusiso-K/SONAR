## Scope note — read before applying this to the board

taste-skill's own first line: *"Landing pages, portfolios, and redesigns.
Not dashboards, not data tables, not multi-step product UI."*

SONAR's board IS a dashboard with a data table. Reskinning it in a
landing-page aesthetic would misapply the skill by its own instructions, and
would trade scannability for decoration on the screen we actually operate
from daily.

Where it genuinely applies: `web/app/about` — the public page explaining what
SONAR is. That is a landing page, and it gets the full treatment.

What transfers to the board regardless: the Anti-Default Discipline list
(§0.D) and the Design Read habit. Both already shaped the board's palette —
brand hue separated from semantic urgency, no AI-purple, not Inter.
