## Security notes

- No new secret reaches the browser: OpenRouter is called from server
  functions only; the existing "no secrets in the bundle" e2e test passes.
- The `debriefs` table accepts inserts from the public key, as the
  watchlist does. Bounded by the policy described in
  [ARCHITECTURE.md](ARCHITECTURE.md). Debriefs are not fed to any model
  prompt, so a forged one is a wrong note, not an injection.
- Model output is never stored unchecked (debrief fields against the
  person's text; sweep findings against the page).
- There is no blockchain or smart-contract code in this repository, so there
  was nothing of that kind to audit.
- A gitleaks step was not added to CI: it could not be trial-run in this
  session, and an untested secret scanner can block every pull request on
  old history. GitHub's own secret scanning remains the control.
