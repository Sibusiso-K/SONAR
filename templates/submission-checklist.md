# Submission checklist — <hackathon>

Run this the day **before** the deadline. Not on it.

## Rules
- [ ] Reread the rules page today
- [ ] Reread the judging criteria — does the submission speak to each one?
- [ ] Eligibility still holds (team size, age, nationality, student status, entity)
- [ ] Licence matches what's required (some require open source)
- [ ] No disqualifier tripped (OOM, crash, wrong format, missing template)

## Code
- [ ] Repo is public if required
- [ ] Clones clean into an empty directory and runs from the README alone
- [ ] Tested on the **target environment**, not the dev box
- [ ] No secrets, keys or tokens committed — check the git history, not just HEAD
- [ ] Required template / structure followed exactly

## Report / write-up
- [ ] Problem definition and context
- [ ] Constraints named explicitly
- [ ] Design alternatives considered and rejected, with reasons
- [ ] Tools chosen and why
- [ ] Benchmarks with real numbers in a table
- [ ] Screenshots
- [ ] Limitations stated honestly
- [ ] Uses the organiser's template if one exists

## Video
- [ ] Under the stated limit (check the exact seconds)
- [ ] Audio audible on laptop speakers
- [ ] Demo is real, not slideware
- [ ] Structure: problem → demo → how → impact
- [ ] Link is public and plays in a private browser window

## Submission
- [ ] Every required field filled
- [ ] Every link opens in a private window
- [ ] Team members all added on the platform
- [ ] **Submitted at least 24 hours early**
- [ ] Confirmation email received
- [ ] Submission page reloaded in a private window and verified

## After
- [ ] Assets pushed to `entries/_shared/`
- [ ] Retro scheduled within 7 days
